# Аналитическая система

В проекте для шага 3 выбран базовый вариант

## Как запустить

Из корня проекта:

```bash
docker compose up -d analytics-spark-job
```

Посмотреть логи аналитики:

```bash
docker compose logs -f analytics-spark-job
```

## Проверка HDFS

Проверить, что Spark записал данные в HDFS:

```bash
docker exec -it hdfs-namenode hdfs dfs -ls /data/products_validated
```

Посмотреть часть записанных файлов:

```bash
docker exec -it hdfs-namenode hdfs dfs -cat /data/products_validated/* | head
```

HDFS UI:

```text
http://localhost:9870
```

Проверить, что появились рекомендации:

```bash
docker compose exec \
  -e JMX_PORT= \
  -e KAFKA_JMX_PORT= \
  -e KAFKA_JMX_OPTS= \
  dr-kafka-0 /opt/bitnami/kafka/bin/kafka-console-consumer.sh \
  --bootstrap-server dr-kafka-0:9092 \
  --topic recommendations \
  --from-beginning \
  --consumer-property security.protocol=SASL_SSL \
  --consumer-property sasl.mechanism=PLAIN \
  --consumer-property 'sasl.jaas.config=org.apache.kafka.common.security.plain.PlainLoginModule required username="admin" password="admin-password";' \
  --consumer-property ssl.truststore.location=/bitnami/kafka/config/certs/kafka.truststore.jks \
  --consumer-property ssl.truststore.password=123456 \
  --consumer-property ssl.truststore.type=JKS \
  --consumer-property ssl.endpoint.identification.algorithm=HTTPS
```
