# Шаг 5. Система хранения и поиска данных

В проекте для шага 5 выбран расширенный вариант:

1. Kafka Connect читает только отфильтрованные данные из топика `products.validated`.
2. Данные пишутся в Elasticsearch.
3. Коннектор регистрируется автоматически при старте `kafka-connect`.
4. Можно проверить статус коннектора и найти данные через HTTP-запросы.

## Как работает

Поток данных:

`products.raw -> фильтрация -> products.validated -> Kafka Connect -> Elasticsearch`

В  хранилище попадают только отфильтрованные данные, т.к коннектор подписан на топик `products.validated`, а не на `products.raw`.

## Как запустить

Из корня проекта:

```bash
docker compose up -d --build elasticsearch kafka-connect
```

## Проверка

Проверка, что Kafka Connect работает:

```bash
curl -s http://localhost:8083/connectors
curl -s http://localhost:8083/connectors/products-validated-elastic-sink/status
```

Проверка, что данные записались в Elasticsearch:

```bash
curl -s -X POST "http://localhost:9200/products.validated/_search?pretty" \
  -H "Content-Type: application/json" \
  -d '{"query":{"match":{"raw_json.name":"Планшет TabOne 11"}}}'
```

Если нужно посмотреть логи:

```bash
docker compose logs -f kafka-connect
docker compose logs -f elasticsearch
```
