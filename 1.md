## Проект состоит из

1. **Источники данных**: SHOP API и CLIENT API.
2. **Kafka-инфраструктура**: основной кластер из 3 брокеров, DR-кластер, TLS, SASL, ACL, MirrorMaker 2.
3. **Аналитика**: Spark читает данные из DR Kafka, пишет данные в HDFS и рекомендации в Kafka.
4. **Потоковая фильтрация**: Faust фильтрует запрещённые товары.
5. **Хранение и поиск**: Kafka Connect пишет отфильтрованные товары в Elasticsearch.
6. **Мониторинг**: Prometheus, Grafana, Alertmanager, JMX Exporter.

В проекте сделана эмуляция двух API в services:

- **SHOP API** - чтение и отправка в Kafka
- **CLIENT API** - команды в терминале для поиска товара и запроса рекомендаций


1. Файл с товарами лежит в репозитории: `data/products.jsonl`.
2. SHOP API читает товары из файла.
3. Каждый товар отправляется в Kafka topic `products.raw`.
4. Для сообщений используется Avro-схема `schemas/product.avsc`.
5. CLIENT API сделан командами в терминале:
   - поиск товара по имени через Elasticsearch;
   - запрос персонализированных рекомендаций.


## 3. SHOP API

SHOP API эмулируется запуском Python-команды.

Сервис читает товары из файла `data/products.jsonl`, проверяет обязательные поля и отправляет товары в Kafka.

Топик Kafka:

```text
products.raw
```

CLIENT API эмулируется командой в терминале. Поиск идёт через Elasticsearch по индексу products.validated. Пример поиска товара по имени:

```
curl -s -X POST "http://localhost:9200/products.validated/_search?pretty" \
  -H "Content-Type: application/json" \
  -d '{
    "query": {
      "match": {
        "name": "Планшет TabOne 11"
      }
    }
  }'
```

И получить популярные товары (например по количеству зарезервированных)
```
curl -s -X POST "http://localhost:9200/products.validated/_search?pretty" \
-H "Content-Type: application/json" \
-d '{"query": {
  "match_all": {}
},
"sort": [{"stock.reserved": {"order": "desc"}}],
"size": 5}'
```

Добавлен файл ingestion_service/rec_script.py в котором через команду 
```
python services/ingestion_service/rec_script.py
```
открывается окно в которой по команде 
1. search <название> (например search Планшет) будет произведен поиск по имени
2. recommend - получить персонализированные рекомендации. Вам покажут самые популярные товары. Те, которые люди чаще всего заказывают (у которых больше всего зарезервировано в наличии
